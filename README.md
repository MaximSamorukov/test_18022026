# Тестовое задание - Управление балансами игроков

React-приложение для отображения списка устройств и управления балансами игроков.

## Стек технологий

- **Core**: React 19, TypeScript, Vite
- **State Management**: native
- **Styling**: Sass (SCSS), Bootstrap 5, React-Bootstrap
- **UI Components**: react-currency-input-field, react-hot-toast

## Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

### Линтинг

```bash
npm run lint
```
